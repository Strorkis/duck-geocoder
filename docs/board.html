次にやること (この順)

  1. 周辺検索の見直し 触ってみての指摘を待っている (機能を一気に足したので、使い勝手を詰める)
  2. 背景地図もレイヤーにする QGIS と同じく、ラスタも重ねられて不透明度と順番を持つ形に。いまは背景の文字と 地理院の注記が二重に出る
  3. 観点 (汎用の問い合わせのひな形) 複数のデータにまたがる条件に名前を付けたもの。条件はコードではなくデータで持ち、 用途ごとに組み替えられるようにする (ドローンは例の1つ)。周辺検索が土台になる
  4. 国土数値情報を足す 学校 P29 (最新年度はCC BY)・医療機関 P04・福祉施設 P14・公共施設 P02・都市公園 P13。 P04/P14 は許諾が未確認。河川 W05 は使えない (非商用・承認番号付き・2009年度で停止)

済み (2026-10-03、まだ公開していない)

  • 地理院のベクトルタイルを重ねる テーマ9行、開けば層ごと。ズームで入り切りが戻らない。一覧の絞り込み欄 (「送電」で両方の送電線)
  • 段で間引く 標準なら z14 で公共施設・商業・業務、z13 で公共施設だけ。東京駅 z13 で約30MB → 約2MB
  • 周辺検索 (◎) 起点は点・建物・線 (同じ名前をまとめる)・検索結果。50〜500m以内の建物・駅・送電線・川・人口
  • 使う条件のバッジ 商用可か・出典表示・加工の明記・継承を、カードと出典のダイアログに
  • Overture: 版を上げ、建物を全国に、送電線と川を追加 建物は QuadKey で392ファイル (5,419万棟)
  • ダウンロード 表示範囲のGeoParquet・ファイル丸ごと・配布元・CityGML (メッシュ単位の直リンクと公式のZIP)
