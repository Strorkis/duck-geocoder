## 条文は29条 (複製)

**形式を変えるだけで、独自性のある内容を作っていない。**
[事例集](https://www.gsi.go.jp/LAW/2930-sample.html)にそのままの例がある。

> ベクトルデータ等（国土基本情報等）のデータ等を**地図データとして配布**する利用例です。
> → **第29条（複製）**

[Q&A](https://www.gsi.go.jp/LAW/2930-qa.html) Q2-3 も、インターネット等で
「不特定多数の者に対して測量成果が入手又は閲覧可能な状態に置く場合」は承認が要るとしている。
**ここに当たる。**

**Q3-2「同一内容であれば、一つの申請書の中に記載して申請することができます」**
→ 上の表のものを1通にまとめる。

### 当たらない条件

29条の注意事項にこうある。

> **インターネット提供物ではない刊行物**（紙地図・デジタル地図）の場合、
> 原データ項目の削除若しくは独自情報の付加及び測量成果の原データのみを
> 抽出できないことが条件となります。

**条件文が「インターネット提供物ではない」で始まっている。** このリポジトリは
Webで配るので**対象外**。GeoParquetから原データが抽出できることは問題にならない。

## 申請書に書くこと

[29条の様式・記載例](https://www.gsi.go.jp/LAW/2930-29zyou.html)の各欄に当てたもの。

| 欄 | 書く内容 |
| --- | --- |
| 申請者 | (リポジトリの持ち主)。**複製作業者名での申請は認められない** |
| 複製の目的 | Webサイト「(リポジトリ名)」において、置いたデータを必要な分だけ読んで使えることを実証するため |
| 複製する測量成果の種類及び内容 | 国土数値情報（行政区域データ）N03 全国 / 基盤地図情報（基本項目）の水涯線 ほか (上の表) |
| 交付年月日 | **全て最新版を利用する** |
| 複製の範囲又は区域 | 全国 |
| 複製の作業方法 | 座標系の変換 (JGD2011→WGS84)、GeoParquetへの形式変換、空間充填曲線での行の並べ替え、covering bbox列の付加。**図形の加除修正は行わない** |
| 複製の期間 | 承認後1年間 |
| 複製品の利用方法及び配布の範囲 | **Webサイトを通じて広く一般に無償で公開する** |
| 複製品の部数 | 電子データ1式 |
| 複製機関名 | 申請者に同じ |
| 備考 | 二次利用する成果品名と承認番号 (N13なら `R6JHf503`)、連絡担当者 |

**承認まで7〜14営業日** (土日祝を除く)。オンラインは
[測量成果ワンストップサービス](https://service.gsi.go.jp/onestop/navi/nav5-10/)
(無料のユーザ登録)。**判定機能はQ&A以上のことを言わない。**

## 手数料 — いまは無料。**広告を置くと変わる**

Q4-3 が「手数料等の費用は発生いたしません」、Q5-4 が
「営利・非営利に関わらず**基盤地図情報はそのままの複製であっても無償で承認されます**」。
**つまり手数料の話**で、承認の可否ではない。

そして Q5-4 は営利目的の例に
**「インターネットで無償で公開し、バナー広告等により利益を取得する場合」**を挙げている。

| | |
| --- | --- |
| **このサイト** | **広告を置いていないので非営利。** 手数料は発生しない |
| **広告を置いたら** | **営利扱いになり、手数料の対象になりうる** |
| 基盤地図情報 | **営利でも無償。** そのままの複製でも手数料が要らない |

**広告を入れる選択が、データの利用条件に跳ね返る。** 収益化を考えるなら
ここを先に確かめること。

## 二次利用の扱い

Q1-24:

> 承認を得た成果品の利用については、**前提として承認を得た者からの許諾が必要**です。
> 複製承認を得て複製した成果を更に複製・使用する場合は申請が必要な場合があります

N03 は国土数値情報の製品で、N13 は `R6JHf503` を持つ。
**申請書に成果品名と承認番号を書く欄がある**ので、そこに書く。
避けるために製品を変える必要はない。

**承認するのは国土地理院長。** 国土地理院は国土交通省の機関なので、
「国土交通省に聞くか地理院に聞くか」という分け方は成り立たない。
N03も基盤地図情報も相手は同じ。

## どの製品から取るか — 基盤地図情報と国土数値情報の棲み分け

系譜はこうなっている。

```
測量成果 ─→ 電子国土基本図（地図情報）
              ├─ 基盤地図情報            … 無償。位置の基準となる13項目
              ├─ 数値地図（国土基本情報）  … **有償。** 2次メッシュの図郭単位で購入
              └─ 数値地図（国土基本情報20万）… 編集済み・小縮尺
                        ↓ ここを原典として取得
            国土数値情報 N03 行政区域（無償・国土交通省 国土政策局）
```

**数値地図（国土基本情報）は有償**なので、全国を図郭単位で買うのは現実的でない。
残る2つは役割が違う。

| | 基盤地図情報 | 国土数値情報 |
| --- | --- | --- |
| 作っているところ | 国土地理院 | 国土交通省 国土政策局 |
| 何のためのものか | **「どこにあるか」の共通の基準** (地理空間情報活用推進基本法で13項目を規定) | **「それが何か」の情報** (国土政策の推進に資するため) |
| 属性 | **最小限。** 位置の基準なので | **主役。** 行政区域コード、用途地域の種別… |
| 位置の精度 | **都市計画区域で1/2500相当**、その他1/25000相当 | 原典依存。N03は数値地図25000の系統なので**1/25000** |
| 配布 | 図郭単位か都道府県単位 (**要確認**)、無料のユーザ登録 | 都道府県単位・全国。属性付き |

**基盤地図情報の強みは位置の精度**で、都市域では10倍細かい。
**国土数値情報の強みは属性**で、扱いやすい形になっている。

### 決めたこと

| 欲しいもの | どちらから | なぜ |
| --- | --- | --- |
| **行政区域** | **国土数値情報 N03** | 属性 (コード) が付く。市区町村の面に1/2500は要らない |
| **川 (水涯線)** | **基盤地図情報** | N03系に無い。水際の位置は細かい方がよい |
| 町丁目・街区の**境界** | 基盤地図情報 | いま持っているのは位置参照情報の**代表点だけ** |
| 道路 (面) | 基盤地図情報の道路縁 | PLATEAU `tran` は302都市どまり |

### 行政区域コードは何に使うのか

**いまは使っていない。** UIは逆ジオコーディングの結果とポリゴンを
Overtureの `admin_id` (GERS ID) で結んでいる。

**効くのは「日本の公的データを繋ぐとき」。** 市区町村コードは
PLATEAU (5桁の都市コード)・国土数値情報の施設系・位置参照情報が**共通して持つ鍵**。
実際、PLATEAUの整備範囲を調べたときは名前で結ぶことになり、
**ケ/ヶ の表記揺れを正規化してようやく306/306**が一致した。

N03を使えばこの鍵が手に入る。基盤地図情報に替えると失う。
**いま困っていないが、捨てる理由も無い。**
